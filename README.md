# Yash Raj — Developer Portfolio

A responsive personal portfolio for Yash Raj, focused on full-stack development, AI/ML systems, backend engineering, and problem solving.

## Features

- Responsive dark neumorphic design
- Animated hero section and interactive navigation
- Skills grouped by technology area
- Project cards with source code and live demo links
- Coding profiles, certificates, achievements, and education journey
- Contact form and downloadable resume

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Built with React, Vite, Framer Motion, Lucide React, and CSS.
